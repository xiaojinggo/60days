# 每日職場靈修

每日一節聖經經文（和合本），包含默想方向、鼓勵的話與禱告，約 5–8 分鐘。
支援連續打卡天數，並可切換淺色／深色模式。

## 檔案
- `index.html`：頁面程式，通常不需要修改。
- `content.json`：所有靈修內容與起始日，日常更新只改這個檔案。

## 如何更新內容
1. 打開 `content.json`。
2. `startDate` 是第 1 天的日期（格式 `YYYY-MM-DD`）。之後每天自動顯示「第 N 天」。
3. 在 `days` 陣列最後面新增內容，每一天的格式：
   - `r`：經文出處
   - `v`：經文
   - `p`：禱告
   - `e`：鼓勵的話
   - `m`：三個默想問題（陣列）
4. 儲存（Commit）後，網站會在一兩分鐘內更新。
5. 內容用完後不會循環，會顯示「靈修完成」的提示。只要在 `days` 最後面補上新內容，到了第 61 天的日期就會自動顯示。

## 主題經文分頁
`content.json` 裡的 `topics` 是「主題經文」分頁的內容。每個主題的格式：
- `t`：主題名稱，`d`：一句簡短說明
- `v`：經文清單，每筆包含 `r`（出處）與 `v`（經文）
要新增主題，複製一組主題，改成新的名稱和經文即可。

## 注意
- 直接用瀏覽器開啟檔案無法載入內容，請用 GitHub Pages 發布，或在本機啟動簡單伺服器。
- 所有內容皆取自聖經（和合本）。禱告、鼓勵、默想為草稿，正式使用前請經牧者或同工審閱，並逐節核對經文。
