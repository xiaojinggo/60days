# 每日職場靈修

每日一節聖經經文（和合本），包含前後文對照、默想方向、鼓勵的話與禱告，約 5–8 分鐘。
支援連續打卡天數、經文前後文展讀、個人靈修筆記、經文收藏，並可切換淺色／深色模式。

## 檔案說明
- `index.html`：頁面程式與介面邏輯，通常不需要頻繁修改。
- `content.json`：所有靈修內容、前後文資料與起始日，日常維護主要更新此檔案。

## 如何更新內容
1. 打開 `content.json`。
2. `startDate` 是第 1 天的日期（格式 `YYYY-MM-DD`）。之後每天自動顯示「第 N 天」。
3. 在 `days` 陣列中新增或維護內容，每一天的格式：
   - `r`：今日金句出處
   - `v`：今日金句
   - `cr`：前後文出處範圍（例如：`歌羅西書 3:22-25`）
   - `cv`：前後文完整經文（包含節數標註）
   - `p`：禱告文
   - `e`：鼓勵的話
   - `m`：默想問題（陣列）
4. 儲存（Commit）後，網站會在一兩分鐘內更新。

## 功能特色
- **查看前後文**：在今日經文下方點擊「📖 查看前後文」可原處展開上下文經文。
- **經文收藏與筆記**：
  - 每日經文旁點擊 ☆ 即可加入收藏。
  - 頁面下方設有「靈修心得與筆記」，輸入後自動儲存。
  - 「我的收藏」頁籤會集中顯示所有收藏的經文與個人筆記。
  - *註：收藏與筆記儲存於使用者本機瀏覽器（localStorage），完全私密且不跨裝置。*
- **主題經文分頁**：依據不同職場處境分類彙整經文。

## 注意事項
- 請透過 GitHub Pages 發布，或於本機啟動簡易 HTTP 伺服器，直接以瀏覽器雙擊開啟 HTML 檔案可能因安全政策無法載入 JSON 內容。
- 所有內容皆取自聖經（和合本）。
